# Project

This is an example app that showcases ci/cd configurations for a FastAPI app.

## Overview

See @README.md for project overview and @pyproject.toml for project config.

## Commands

- `uv run fastapi dev`: run the app
- `uv run pytest`: run the tests
- `uv run pytest --cov`: run the tests with a coverage report
- `uv run ruff format`: format the code

## Formatting

After adding or changing code, run `uv run ruff format` on the files you touched.
